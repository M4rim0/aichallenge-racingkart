# 設計：戦略計算エンジン（段階10）

> 状態：**実装済み**。関連決定：D-023, D-044〜D-055
> 実装：`src/shared/strategy/`（純粋関数）、`src/main/services/strategy-service.ts`（DB 読み込み）
> AI は使わない。結果は保存せず、取得のたびに元データから再計算する（§8.9, §14）。

## 入力

- 有効な通過記録：自チーム = ラップ記録、他チーム = 通過記録（D-003）。削除済みチームも含む（D-008）
- 実際の開始時刻、終了予定時刻、大会状態、現在日時（マスタークロック。終了後は実際の終了時刻）
- 有効な強制停止時間（D-044）
- 順位ルール（現在は §8.3 暫定ルール、D-023）

## 用語と定義

| 用語 | 定義 | 実測 / 推定 |
|---|---|---|
| 周回数 L | 有効な通過記録の件数（他チームは初回通過 = 1 周、D-020） | 実測 |
| 周回差 | 周回数の差（整数） | 実測 |
| 実測時間差 | **同じ周回数のチーム間のみ**、その周回の通過時刻の差 | 実測 |
| 推定時間差 | 推定走行位置の差 × 後方チームの予測ペース（5 周平均）。**周回数が異なるチーム間の最終通過時刻の単純な差は使わない** | 推定 |
| 走行可能時間 | 時間から強制停止区間（重複は結合）を除いたもの | ― |
| 推定走行位置 Q | `L + Δt / P`。Δt = 最後の通過（自チームで 0 周なら実際の開始時刻）から現在までの走行可能時間。進捗率は 0〜1 に制限（§8.4, D-046） | 推定 |
| R_clock | 終了予定時刻 − 現在 | ― |
| S_remaining | 現在〜終了予定の強制停止時間（重複は結合） | ― |
| R_drive | `max(0, R_clock − S_remaining)`（§8.5） | ― |

## 平均ペース（D-045, D-047〜D-049）

- 直近 N 周（N = 3, 5, 10）の**有効な**ラップタイムの単純平均。有効なラップが N 件未満なら算出しない（データ不足、使用できた件数を返す）。
- 除外するラップ（理由付きで返す）：
  - `NO_BASE_TIME`：他チームの 1 周目（基準時刻なし）
  - `STOPPAGE_OVERLAP`：強制停止と時間的に重なったラップ（停止時間を差し引いて使うことはしない）
  - `NON_POSITIVE`：ラップタイムが 0 以下（時刻異常など。計算を破綻させないため）
- 含めるラップ：自チームの 1 周目、アプリの PAUSE をまたいだラップ。
- ペースの変化：3 周平均 − 10 周平均（ms と %）。負 = ペース上昇（FASTER）、正 = 低下（SLOWER）。判定しきい値は段階11以降。

## シナリオ

3 周平均・5 周平均・10 周平均をそれぞれ予測ペース P とする 3 シナリオ（`avg3` / `avg5` / `avg10`）。前方・後方とのペース差は 5 周平均が標準（D-050）。

## 最終周回数の予測（D-051）

1. 最後の通過から P だけ走行可能時間を積み上げた時刻を次の通過とする（停止区間は飛ばす）。
2. 次の通過予測が既に過ぎている（未通過のまま遅れている）場合は「現在」に通過するものとする（`overdueAdjusted`、不確実性 `OVERDUE`）。
3. 以降 P ごとに通過し、**終了予定時刻以前に完了する通過だけ**を数える（終了時刻ちょうどは含む）。
   - 残り時間 ÷ ペースを単純に切り捨てるのではなく、実際の最後の通過からのタイミングで数える。
4. 予測最終順位は、予測最終周回数と予測上の最後の通過時刻を順位ルールに当てはめて求める。
   予測できないチーム（データ不足など）は現在の進捗のまま並べ、`predicted = false` とする。

## 攻撃・防衛（§8.6, §8.7, D-052）

推定走行位置 Q の差 G（小数の周）と R_drive を使う。

- 攻撃（直上のチーム、ペース Pt、G = Q_相手 − Q_自）：`P_req = 1 / (1/Pt + G/R)`
  - P_req で走ると終了時に**並ぶ（追いつく）**。P_req より短いペースなら**追い抜く**。
  - 分母 ≤ 0 → `AHEAD_EVEN_IF_STOPPED`（数値を出さない）
- 防衛（直下のチーム、ペース Pb、G = Q_自 − Q_相手）：`P_req = 1 / (1/Pb − G/R)`
  - P_req より短いペースなら**追いつかれない**、P_req 以下なら**抜かれない**。
  - 分母 ≤ 0 → `SAFE_EVEN_IF_STOPPED`（相手のペースでは自チームが走らなくても追いつけない）
- R_drive ≤ 0 → `NO_TIME`、位置・ペースがない → `NO_DATA`
- `paceMarginMs` = P_req − 自チームの予測ペース（負ならペースアップが必要）
- 周回の完了（通過）で決まる実際の順位とは一致しない場合がある推定値。

## 抜ける・抜かれる可能性（D-053）

各シナリオで、現在の順位と予測順位の前後が入れ替わる組み合わせを、**どのシナリオか**とともに返す（両チームとも予測できたシナリオのみ）。現在順位は変更しない（可能性と確定事項を区別）。

## 強制停止時間（D-044〜D-046）

- 重複・隣接する区間は結合し、二重計上しない。
- 終了日時が未定の停止は「max(開始, 現在)」で終わるものとして計算する（分かっている最小の停止時間）。**確定値ではない**ため、結果に `OPEN_ENDED_STOPPAGE` を付ける。
- 現在停止中なら `IN_STOPPAGE`。Δt は停止時間を除くため、停止中は推定位置が進まない。

## 不確実性（結果に付くフラグ）

| フラグ | 意味 |
|---|---|
| PROVISIONAL_RANKING_RULE | 順位が暫定ルール |
| INSUFFICIENT_DATA | 平均に必要なラップ数が足りない |
| OVERDUE | 予測ペースを過ぎても次の通過記録がない（記録が古い・ペース低下・記録漏れの可能性） |
| NO_REFERENCE | 位置の基準となる通過がない |
| OPEN_ENDED_STOPPAGE | 終了未定の強制停止がある |
| IN_STOPPAGE | 現在強制停止中 |
| NO_SCHEDULED_END | 終了予定時刻が未設定（予測・攻撃防衛は算出しない） |
| RACE_NOT_STARTED / RACE_FINISHED | 開始前 / 終了後（終了後の「予測」は実績そのもの） |
| TIMELINE_ANOMALY | 現在日時が最後の通過より前（時刻異常） |

## 計算根拠として返す値（D-054）

平均ペースと使用ラップ数・除外ラップと理由、現在の周回数・推定走行位置（Δt・進捗率）、前方・後方との周回差・実測／推定時間差・ペース差、R_clock・S_remaining・R_drive・これまでの停止時間、各シナリオの予測最終周回数・次の通過予測・予測上の最終通過・予測順位・順位変動、攻撃・防衛の G・相手ペース・必要ペース・余裕、不確実性。
表示方法は UI 設計時に決める。
